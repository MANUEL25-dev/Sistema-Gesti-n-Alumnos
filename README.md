# Sistema de Gestión de Alumnos

**Una solución de escritorio desarrollada en Java para administrar información escolar de manera sencilla, organizada y eficiente.**

Este proyecto fue desarrollado como parte de la asignatura **Tópicos Avanzados de Programación**, utilizando Java y NetBeans, con conexión a una base de datos MySQL para gestionar la información de los alumnos.

El sistema busca facilitar las tareas básicas de administración escolar mediante una interfaz gráfica que permite registrar, consultar, modificar y eliminar información, manteniendo los datos centralizados en una base de datos.

## Funcionalidades principales

- **Registrar alumnos:** guardar nuevos registros con información como número de control, nombre, dirección y otros datos escolares.
- **Consultar información:** buscar y visualizar los registros de los alumnos.
- **Modificar registros:** actualizar los datos almacenados cuando sea necesario.
- **Eliminar alumnos:** eliminar registros que ya no se requieran.
- **Conexión con MySQL:** almacenar y consultar información mediante una base de datos relacional.
- **Interfaz gráfica:** facilitar la interacción con el sistema sin depender exclusivamente de comandos de consola.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso en el proyecto |

| Java | Desarrollo de la lógica de la aplicación. |
| NetBeans IDE | Entorno de desarrollo del proyecto. |
| MySQL | Gestión y almacenamiento de la información. |
| JDBC | Conexión entre Java y la base de datos. |
| WampServer | Entorno local utilizado para trabajar con MySQL. |

## ¿Qué aprendí con este proyecto?

El desarrollo de este sistema me permitió reforzar conocimientos de programación orientada a objetos, conexión de aplicaciones Java con bases de datos, operaciones CRUD y desarrollo de interfaces gráficas.

También me permitió comprender la importancia de mantener la información organizada, facilitar las operaciones de administración y conectar los componentes de una aplicación para construir una solución funcional.

## Requisitos para ejecutarlo

- Java JDK compatible con el proyecto.
- Apache NetBeans IDE.
- Servidor MySQL.
- Controlador JDBC para MySQL.
- Base de datos `alumnos4a`.

## Instalación y ejecución

1. Clonar o descargar este repositorio.
2. Abrir el proyecto desde Apache NetBeans.
3. Iniciar el servidor MySQL.
4. Importar la base de datos `alumnos4a` en MySQL, utilizando el respaldo SQL correspondiente.
5. Verificar la configuración de conexión en la clase `ConectarBD`.
6. Ejecutar el proyecto desde NetBeans.

**Nota:** La base de datos debe estar disponible y la conexión debe configurarse de acuerdo con el entorno local. El respaldo SQL se agregará al repositorio cuando esté disponible.

## Objetivo del proyecto

Desarrollar una aplicación de escritorio que permita gestionar información de alumnos mediante operaciones básicas de administración y una conexión a MySQL, aplicando los conocimientos adquiridos durante la formación en programación.
